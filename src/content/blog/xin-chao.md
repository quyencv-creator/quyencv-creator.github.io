Đây là bài viết đầu tiên. Để viết bài mới, tạo file `.md` trong `src/content/blog/`:

```md
---
title: Tiêu đề bài
description: Mô tả ngắn
pubDate: 2026-11-21
tags: [ghi-chu]
draft: false
---

Nội dung viết bằng **Markdown**.
```

Sau đó `git add`, `git commit`, `git push` — GitHub Actions sẽ tự build và đăng bài.
